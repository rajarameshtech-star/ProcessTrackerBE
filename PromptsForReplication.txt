**Prompt 1:**
"In my .NET 8 API project, my `Middlewares/LoggingMiddleware.cs` is inappropriately disposing of the incoming HTTP request stream, leading to 'Cannot access a disposed object' 500 errors in downstream Model Binders. `using (var reader = new StreamReader(request.Body, System.Text.Encoding.UTF8, true, 1024, true))`

**Prompt 2:**
"In `Repositories/RecordRepository.cs`, my dynamic LINQ search is failing translation in Entity Framework Core because ASP.NET maps unknown dynamic POST dictionaries into `System.Text.Json.JsonElement`. 
Provide the updated code for `GetRecordsByProcessDefinitionWithFiltersAsync`. For `FieldType.Text` and dropdown filters inside the loop, extract the `stringValue` EXACTLY like this:
```csharp
var (fieldType, rawValue) = parsedFilter.Value;
string stringValue = "";
if (rawValue is System.Text.Json.JsonElement je && je.ValueKind == System.Text.Json.JsonValueKind.String) {
    stringValue = je.GetString() ?? "";
} else {
    stringValue = rawValue?.ToString() ?? "";
}
int fieldId = processField.Id; // local primitive for EF closure
```
Then use `fieldId` and `stringValue` in the `.Any(fv => fv.ProcessFieldId == fieldId && ...)` EF Core `IQueryable` statements."

### Phase 2: ProcessFields Endpoints
**Prompt 5:**
"I need you to write `Requests/CreateProcessFieldRequest.cs` and `Requests/UpdateProcessFieldRequest.cs`. 
They must both contain these standard validation mappings:
string Label
bool IsRequired
int SortOrder
string? Placeholder
string? DefaultValue
string? OptionsJson
int? MinLength, int? MaxLength
decimal? Min, decimal? Max
string? Pattern
bool IsActive
NOTE: `CreateProcessFieldRequest` needs two additional required properties: `int ProcessDefinitionId` and `string FieldName`. `UpdateProcessFieldRequest` does NOT contain these two properties because they are immutable."

**Prompt 6:**
"Write `Interfaces/RepositoryInterfaces/IProcessFieldRepository.cs` and `Repositories/ProcessFieldRepository.cs`. 
`IProcessFieldRepository` needs to inherit `IGenericRepository<ProcessField>`. 
Implement these 3 methods natively inside `ProcessFieldRepository` using Entity Framework `ApplicationDbContext`:
1. `Task<List<ProcessField>> GetFieldsByProcessDefinitionAsync(int processDefinitionId)` (use `.OrderBy(pf => pf.SortOrder)`)
2. `Task<ProcessField?> GetFieldWithDefinitionAsync(int id)` (use `.Include(pf => pf.ProcessDefinition)`)
3. `Task<bool> HasRecordsAssociatedAsync(int fieldId)` (check if `_context.ProcessRecordFieldValues.AnyAsync(fv => fv.ProcessFieldId == fieldId)` is true)."

**Prompt 7:**
"Write `Interfaces/ServiceInterfaces/IProcessFieldService.cs` and `Services/ProcessFieldService.cs`. 
Dependencies: `IProcessFieldRepository` and `IProcessDefinitionRepository`.
Required Methods:
- `CreateProcessFieldAsync`: throw a `ValidationException` (using `new Dictionary<string, string> { { "FieldName", "Field Name is required" } }`) if `FieldName` clashes with `existingFields.Any(f => f.FieldName.Equals(...))` or if `Label` is empty/null.
- `UpdateProcessFieldAsync`: map over the existing fetched fields properties, except `FieldName` and `ProcessDefinitionId`.
- `GetProcessFieldAsync` and `GetFieldsByProcessDefinitionAsync`.
- `DeleteProcessFieldAsync`: throw an `InvalidOperationException` if `HasRecordsAssociatedAsync` returns true.
- `ToggleActiveStatusAsync`: swaps `IsActive = !IsActive`."

**Prompt 8:**
"Draft `Controllers/ProcessFieldsController.cs`. 
Add `[ApiController]` and `[Route("api/process-fields")]`.
Expose explicit endpoints mapping to the Service tasks:
- `[HttpPost]` -> `CreateProcessField`
- `[HttpGet("{id}")]` -> `GetProcessField`
- `[HttpGet("process/{processDefinitionId}")]` -> `GetFieldsByProcessDefinition`
- `[HttpPut("{id}")]` -> `UpdateProcessField`
- `[HttpDelete("{id}")]` -> `DeleteProcessField`

Use `try/catch` wrapping for `NotFoundException` (return 404), `ValidationException` (return 400), and `InvalidOperationException` (return 409). Inject `IProcessFieldService`."
